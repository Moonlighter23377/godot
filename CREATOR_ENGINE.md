
# Creator Engine

Creator Engine is an experimental game engine built on Godot Engine.

## Our goals

1. Make advanced game development accessible to beginners.
2. Improve real-time rendering quality and performance.
3. Integrate a collection of visual editing studios.
4. Provide visual logic alongside GDScript.
5. Support reusable systems for different game genres.
6. Maintain compatibility with upstream Godot wherever practical.

## Technical foundation

- Upstream engine: Godot
- Initial base: 4.7.2-stable
- Primary editor platform: Windows x86-64
- Initial renderer target: Vulkan / Forward+
- Engine language: C++
- Gameplay scripting: GDScript
- Build system: SCons

## Development principles

- Keep changes modular.
- Preserve existing Godot capabilities.
- Measure performance before optimizing.
- Implement small, testable engine changes.
- Maintain a clean upstream integration strategy.
- Write documentation for new features.
